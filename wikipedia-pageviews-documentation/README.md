# Documentation for Wikipedia Pageviews Data (for study use)

To load the DP documentation, do the following:

1. Download the DP-documentation folder to your machine.
2. Open the terminal and navigate to abovementioned folder.
3. Start a local server (e.g., by running ```python -m http.server```).
4. Paste the server URL (e.g., ```http://0.0.0.0:8000/```) into your browser and the documentation should load!

Follow a similar process for the other sets of documentation.

If you want to open multiple documentations at once, then make sure you start different local servers for each. You will need to specify different ports after the first one: when starting servers following the first one, run ```python -m http.server 8001``` (or something other four-digit number).
